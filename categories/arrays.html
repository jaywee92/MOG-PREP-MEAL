Problem Snapshot

Given an integer array nums, return true if any value appears at least twice, and false if every element is distinct.

DESCRIPTION

We only need to know if a duplicate exists. As soon as we detect one repeated value, we can stop and return immediately.

Input: [1,2,3,1]\nOutput: true
Input: [1,2,3,4]\nOutput: false
Input: [1,1,1,3,3,4,3,2,4,2]\nOutput: true

This matches your slide logic: outer pointer fixes one value, inner pointer scans remaining values to check equality.

Approach B: Hash Set O(n)

Use a set named seen. Iterate once:

1) If current number is already in seen -> duplicate found -> return true

2) Otherwise add number to seen

3) If loop ends, return false

Set lookup/insert is average O(1), so total runtime is O(n).

Reference Implementations (Python)

Baseline (nested loops)

def contains_duplicate_bruteforce(nums):
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] == nums[j]:
                return True
    return False

Optimal (set)

def contains_duplicate(nums):
    seen = set()
    for value in nums:
        if value in seen:
            return True
        seen.add(value)
    return False

# Equivalent one-liner:
# return len(set(nums)) != len(nums)

SET PROPERTY: UNIQUE

Duplicates are not stored twice. This is exactly why duplicate detection is natural with a set.

SET PROPERTY: UNORDERED

Order is not guaranteed. We only care about membership, not position.

SET INTERNALLY

Python sets are hash-table based. Average lookup/insert/delete is O(1).
