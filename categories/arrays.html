Arrays #1: Duplicate Values

One clear lesson, one clear result. We solve this together in six simple parts so it feels easy on the first read.

Task Problem Visualization Pseudocode Python Conclusion

1) Task

We receive a list of numbers called nums.

Return true if any number appears more than once. Otherwise return false.

2) Problem

What do we know, and what do we need to decide?

Input

A list of integers like [1,2,3,1].

Output

true if there is a duplicate, otherwise false.

Good Example

[1,2,3,1] -> true (because 1 appears twice).

No Duplicate Example

[1,2,3,4] -> false (all numbers are different).

Duplicate = same value appears again Set = remembers unique values

4) Pseudocode

This is the simple plan, without Python syntax details.

1Create empty set called seen
2For each value in nums:
3If value is already in seen, return true
4Else add value to seen
5If loop ends, return false

5) Python Code

Same idea, now in real Python.

Python 3 
def contains_duplicate(nums):
    seen = set()

    for value in nums:
        if value in seen:
            return True
        seen.add(value)

    return False

6) Conclusion

You now understand this problem in a clean, beginner-friendly way.

We scan once from left to right.
The set stores only unique values we already saw.
If a value is already in the set, we instantly return true.
Time complexity is O(n), space complexity is O(n).
